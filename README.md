# Life Changer — HTML prototype

Open `index.html` directly in a modern browser. No install, server, or build step is needed.

The prototype stores all edits in the browser under `lifeChanger.v2`, so changes remain after refresh. Existing `lifeChanger.v1` data is migrated on first open while preserving learning records, attempts, and notes. Use **Reset prototype data** in the sidebar and confirm the dialog to restore the original sample data.

It includes dashboard priorities and study streaks, motivation CRUD, a calendar with notes and domain activity dots, reusable Behaviour/Java/DDIA question reviews, and DSA spaced reviews with checkboxes, urgency labels, LeetCode links, and problem detail notes. Functional Coding and System Design task detail screens are also included.
